# 기술 분석표 — M1-2 AI 비서

과제 명세가 프레임워크·DB·AI를 지정하고 있어 선택의 폭은 좁다. 대신 **무엇을 왜 그렇게
구성하는지**와, 이 구성이 **Final Project까지 어떻게 이어지는지**를 명시적으로 남긴다.

## 1. 기술 스택 결정

| 영역 | 선택 | 선정 이유 |
|---|---|---|
| 데이터 출처 | 한국관광 데이터랩 월별 방한 외래관광객 통계 | M1-1에서 검증한 139개 월별 관측치(2015-01~2026-07)를 재사용한다. 과제의 100건 이상 시계열 요건을 충족하고, 원본 CSV를 이 저장소에 포함해 재현 가능하게 한다. |
| 백엔드 | FastAPI | 과제 지정. 라우터(`routers/`)·서비스(`services/`)·스키마(`schemas/`)로 분리해 각 계층의 책임을 명확히 함 — Pydantic이 요청 검증, 서비스가 Firestore·GPT 호출을 담당 |
| DB | Firebase Firestore | 과제 지정. NoSQL 문서 구조가 `data`(시계열 레코드)와 `conversations`(가변 길이 메시지 배열)처럼 스키마가 서로 다른 두 컬렉션을 다루기에 적합 |
| AI | OpenAI GPT API | 과제 지정. `/api/data/summary` 결과를 시스템 프롬프트에 주입하는 컨텍스트 주입 패턴으로 "내 데이터를 아는 비서"를 구현 |
| 프론트엔드 | 바닐라 HTML/CSS/JS | 과제 지정(프레임워크 금지). 컴포넌트 상태 관리가 필요 없을 만큼 화면이 단순(채팅·CRUD 폼·대화 목록) |
| 배포 | 백엔드 Render / 프론트 Vercel | 과제 지정. 무료 티어 콜드스타트는 프론트에 "첫 응답이 늦을 수 있습니다" 안내 문구로 대응 |

## 2. 데이터 스키마 설계 근거

`data` 문서:

```json
{ "date": "2025-03", "value": 1614596, "memo": "전국 월별 방한 외래관광객 수 (한국관광공사)" }
```

- `value`를 **월별 방한 외래관광객 수**로 고정한 이유: M1-1에서 분석·검증한 공식 시계열을
  재사용해 데이터 출처와 분석 주제를 일관되게 유지하기 위해서다.
- `memo`에는 지표와 출처를 기록한다. 나중에 실제 순례 인증 수로 확장할 때도
  `value=인증수, memo=지표·지역명` 형태로 스키마를 유지할 수 있다.

## 3. Final Project 연결 — 왜 지금 이렇게 설계하나

Final Project(240시간, 캡스톤)는 AI Agent를 핵심으로, 실사용자 5명 이상에게 서비스를
제공하고 피드백을 반영해야 한다. 필수 기술 요소(AI Agent / RAG / 멀티모달 / 자동화
워크플로우 / Long-term Memory) 중 2개 이상을 포함해야 한다.

M1-2에서 만드는 "데이터 요약 기반 챗봇"은 이 요건들의 **최소 골격**과 정확히 겹친다:

| M1-2에서 하는 일 | Final Project 요건과의 관계 |
|---|---|
| 데이터 요약을 시스템 프롬프트에 주입 | RAG의 축소판 — "검색"이 요약 API 호출로 단순화된 형태. M2/M3에서 실제 문서 검색(벡터 DB)으로 확장하면 RAG 요건 충족 |
| `conversations` 컬렉션에 대화 저장·불러오기 | Long-term Memory의 기초 데이터 구조. 지금은 세션 단위지만, 사용자별 프로필과 묶으면 그대로 Long-term Memory 요건 충족 |
| Firestore `data` 스키마를 방문자 수 → 순례 인증 수로 교체 가능하게 설계 | visitholykorea 실사용자가 쌓이면 이 챗봇이 "관리자용 AI 비서"로 전환 — Final Project의 "실사용자 5명 이상 피드백" 요건을 이미 존재하는 앱 사용자로 채울 수 있는 경로 |

**결론**: M1-2는 독립된 과제 제출물로 완결하되(과제 스펙을 벗어나는 기능을 지금 추가하지
않음), 스키마와 컨텍스트 주입 구조만큼은 M2·M3를 거쳐 Final Project로 그대로 이어받을 수
있게 잡아둔다. 각 단계에서 실제로 무엇을 더할지는 M2·M3 명세를 확인하며 다시 정한다.
